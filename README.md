# Dogen Capital 程序介绍

## 项目定位

Dogen Capital 是一个面向个人交易者的小型交易记录网站，用来集中管理交易日志、资金变化和交易思考。  
它不是券商终端，也不是自动化交易系统，而是一套偏向复盘、记录、整理和观察的交易工作台。

这个程序特别适合下面这类使用场景：

- 记录每一笔交易的入场、出场、持仓时长和盈亏情况
- 在仪表盘中快速查看当前账户状态
- 通过思考笔记沉淀交易复盘、策略灵感和市场观察
- 在同一台设备或同一个网站里，为两位使用者分别维护独立数据

---

## 核心功能

### 1. 仪表盘

仪表盘是整个系统的总览页，用来快速查看交易结果和账户状态。

当前包含以下核心板块：

- 本金
- 净盈亏
- 胜率
- 持仓中
- 净值曲线
- 资产分布
- 月度盈亏

其中本金支持手动自定义修改，并且会本地保存。  
净值曲线会结合本金与累计净盈亏展示整体变化。  
资产分布会优先反映当前持仓和现金本位，而不是把已经结束的盈利资产继续挂在持仓结构中。

---

### 2. 交易日志

交易日志是这个程序最核心的模块，用来记录每一笔交易。

支持记录的信息包括：

- 标的代码和名称
- 多空方向
- 持仓状态
- 入场时间
- 出场时间
- 入场价格
- 出场价格
- 当前价格
- 数量
- 手续费
- 标签
- 策略类型
- 备注

在展示上，交易日志也做了专门优化：

- 持仓中的订单会始终排在最前
- 已完成交易会按日期排序
- 表格支持固定表头
- 行距和留白更适合长时间查看
- 全部列内容已统一居中显示
- 可以查看持仓时长

持仓时长筛选目前支持以下区间：

- 1小时内
- 1 - 24小时
- 1 - 3 Day
- 3 - 7 Day
- 7天以上

这让使用者可以更容易按交易风格拆分自己的操作，例如日内、隔夜、短波段等。

---

### 3. 思考笔记

思考笔记模块用于保存交易之外的重要内容，例如：

- 市场判断
- 行业观点
- 个股观察
- 策略总结
- 情绪复盘

标签系统已经改成完全自定义模式，不依赖预设标签。  
用户可以自由输入任意标签，并且支持标签筛选与清空全部标签。

这部分设计的核心目标不是做知识库，而是让交易中的想法、错误、经验和判断都能沉淀下来。

---

## 双用户模式

为了适配两个人一起使用的场景，程序现在支持轻量双用户模式。

当前内置两个用户身份：

- 我
- 女朋友

切换用户后，下列内容会自动切换为该用户自己的独立数据：

- 仪表盘
- 交易日志
- 思考笔记
- 本金设置

这意味着两位使用者可以共用同一个网站入口，但又不会互相混淆彼此的数据。

这个模式的特点是：

- 实现轻量，不需要复杂账号体系
- 不需要数据库
- 数据仍然保存在浏览器本地
- 适合家庭、情侣或小范围共用

---

## 数据导入与导出

程序支持本地文件导入导出，不依赖服务器存储。

### 单独导出

当前选中的用户可以单独导出：

- 交易记录 JSON
- 交易记录 CSV
- 思考笔记 JSON

### 完整双人备份

程序还支持导出完整双人数据包。  
这个备份文件会一次性打包：

- 两位用户的交易记录
- 两位用户的思考笔记
- 两位用户各自的本金设置

导入时也支持：

- 合并导入
- 覆盖导入

如果导入的是完整双人备份包，就可以一次性恢复两个人的数据。

---

## 登录与访问保护

程序已经支持密码访问保护，适合部署到自己的服务器上使用。

当前安全设计包括：

- 登录页密码验证
- 服务端会话 Cookie
- 路由访问拦截
- 登录失败限制
- 退出登录

如果部署在公网服务器上，建议搭配：

- Nginx 反向代理
- HTTPS
- PM2 进程守护

这样可以把程序作为一个私人交易记录站点长期运行。

## 界面风格

整体界面已经从早期偏黑的压抑风格，调整为更轻的暖灰米色系风格。  
同时保留亮色 / 暗色主题切换，并重新分配了页面布局比例，让核心内容区占比更大，导航区更轻。

设计目标不是做金融终端式的复杂界面，而是让页面更适合：

- 长时间浏览
- 快速记录
- 高频复盘
- 减少视觉压力

---

## 技术结构

项目基于以下技术栈构建：

- Next.js 15
- React 19
- TypeScript
- Tailwind CSS
- Zustand
- Recharts

其中：

- 页面和交互由 Next.js + React 实现
- 状态管理使用 Zustand
- 样式系统基于 Tailwind CSS
- 图表展示使用 Recharts
- 本地数据持久化依赖浏览器 localStorage

---

## 适合的人群

这个程序比较适合：

- 个人投资者
- 短线或波段交易者
- 喜欢复盘的人
- 想把交易记录和交易思考放在一起管理的人
- 想和伴侣一起使用同一个记录网站的人

---

## 总结

Dogen Capital 的核心价值，不在于替代券商，而在于帮助交易者建立自己的交易记录系统。

它把“账户概览、交易明细、交易思考、双用户切换、本地备份、密码访问”整合到一个轻量但完整的网站里，让个人交易记录这件事更长期、更有结构，也更容易坚持下去。
