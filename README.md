# Dogen Capital 程序说明

## 项目简介

Dogen Capital 是一套为个人交易者设计的交易记录与复盘网站。

它的核心目标不是替代券商软件，而是帮助你把下面这些事情长期、稳定地管理起来：

- 记录每一笔交易
- 查看账户表现
- 追踪资金变化
- 保存交易思考与复盘
- 让两位使用者共用同一个网站并保持各自独立的数据视图

现在这套程序已经从“浏览器本地记录工具”升级成了“服务器同步版交易记录站点”。

也就是说：

- 两台电脑可以看到同一份服务器数据
- 数据更新会写入服务器
- 数据导出会从服务器下载到本地
- 两位用户可以在同一个网站里切换使用

---

## 核心页面

### 1. 仪表盘

仪表盘负责展示账户整体状态，目前包含：

- 本金
- 净盈亏
- 胜率
- 持仓中
- 净值曲线
- 资产分布
- 月度盈亏

其中本金支持单独修改，并且现在会保存到服务器，而不是只保存在本机浏览器里。

净值曲线基于“本金 + 累计净盈亏”计算。  
资产分布基于“当前持仓 + 现金 / 本位”展示，不会把已经结束并落袋的盈利资产继续错误地留在持仓结构中。

---

### 2. 交易日志

交易日志是最核心的功能模块，用于记录每一笔交易。

支持记录：

- 标的代码和名称
- 多空方向
- 持仓状态
- 入场时间
- 出场时间
- 入场价格
- 出场价格
- 当前价格
- 数量
- 手续费
- 标签
- 策略类型
- 备注

当前表格体验包括：

- 持仓中永远排在最前
- 已完成交易按日期排序
- 固定表头
- 全列居中显示
- 行高和留白优化
- 支持持仓时长查看和筛选

持仓时长筛选支持：

- 1小时内
- 1 - 24小时
- 1 - 3 Day
- 3 - 7 Day
- 7天以上

---

### 3. 思考笔记

思考笔记模块用于保存交易之外的重要内容，例如：

- 市场观察
- 行业判断
- 个股观点
- 策略总结
- 复盘记录

标签系统已经改成完全自定义模式：

- 不依赖预设标签
- 可以任意新增标签
- 支持标签筛选
- 支持清空全部标签

这部分的重点不是做传统知识库，而是帮助你把交易中的判断、反思和经验沉淀下来。

---

## 双用户模式

系统当前内置两位用户：

- 我
- 女朋友

切换用户后，下列内容会自动切换为该用户自己的独立数据：

- 仪表盘
- 交易日志
- 思考笔记
- 本金设置

这意味着：

- 你们使用同一个网站
- 但看到的是各自独立的数据视图
- 互不混淆

---

## 数据同步方式

这是当前版本最重要的升级点。

### 旧版本

旧版本的数据主要保存在浏览器本地 `localStorage` 中。  
这会导致：

- 同一个网站地址，在两台电脑上数据不一致
- 换浏览器后数据也可能不同
- 一台电脑上的更新不会自动同步到另一台电脑

### 当前版本

当前版本改成了“服务器为主”的同步模式：

- 交易数据保存在服务器
- 思考笔记保存在服务器
- 本金设置保存在服务器
- 前端进入网站后会先从服务器拉取最新快照
- 页面会定时同步服务器最新数据
- 当浏览器重新聚焦时也会再次同步

因此现在的行为是：

- 你在电脑 A 上新增或修改数据
- 数据写入服务器
- 你女朋友在电脑 B 上刷新、聚焦或下一轮同步后，就能看到相同结果

## 导入与导出

当前导入导出已经改成“服务器驱动”模式。

### 导出

导出时，文件不是从当前浏览器缓存拼出来的，而是直接从服务器读取后下载到本地。

支持：

- 当前用户交易记录 JSON
- 当前用户交易记录 CSV
- 当前用户思考笔记 JSON
- 完整双人数据包 JSON

完整双人数据包会包含：

- 两位用户的交易记录
- 两位用户的思考笔记
- 两位用户的本金设置

### 导入

导入流程是：

1. 在本地选择文件
2. 浏览器先解析并预览结果
3. 确认后上传到服务器
4. 服务器写入数据库
5. 两台电脑随后同步到同一份数据

导入支持：

- 合并导入
- 覆盖导入

## 登录与安全

程序支持密码访问保护，适合部署在自己的服务器上。

当前已实现的保护包括：

- 登录页密码验证
- 服务端会话 Cookie
- 路由访问拦截
- 登录失败限制
- 退出登录

建议部署在公网时搭配：

- Nginx
- HTTPS
- PM2

这样可以把它作为自己的私人交易记录网站长期运行。

## 技术结构

当前项目主要基于：

- Next.js 15
- React 19
- TypeScript
- Tailwind CSS
- Zustand
- Recharts
- Prisma
- SQLite

大致职责如下：

- Next.js：页面、API、服务端能力
- React：页面交互
- Zustand：前端状态管理
- Recharts：图表展示
- Prisma：数据库访问
- SQLite：服务器端数据存储

## 当前版本的特点

这套程序目前的定位可以概括为：

- 轻量，但不是玩具
- 私人使用为主，但支持双人共享入口
- 结构简单，但已经具备服务器同步能力
- 既适合本地记录，也适合部署到自己的云服务器长期使用

- 个人投资者

- 习惯复盘的人

## 总结

Dogen Capital 的价值不在于替代券商，而在于帮交易者建立自己的交易记录系统。

它把账户概览、交易记录、思考笔记、双用户切换、服务器同步、导入导出和密码访问整合成了一个完整的网站，让交易记录这件事更长期、更有结构，也更容易坚持下去。
